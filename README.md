# Singapore HDB Homeownership Calculator

A browser-based planning tool for comparing HDB purchase scenarios, monthly housing cash flow, CPF OA use, opportunity cost, and illustrative home equity. The default values are rounded sample assumptions, not a person's financial profile.

## Files

- `hdb-opportunity-calculator.html` — interactive calculator. Open it in a modern browser; no build step is required.
- `singapore-hdb-options.md` — public-data sources, model assumptions, and guidance for interpreting the scenarios.

## Notes

The calculator is an illustrative planning aid, not financial or housing advice. Its outputs depend on editable assumptions and simplified models. Verify current eligibility, financing, grants, taxes, CPF contributions, and transaction rules with HDB, CPF, and IRAS before making decisions.
